# PCS‑Loc: Propagation Consistency‑based Rumor Source Localization

## Description
PCS‑Loc identifies the rumor source in social networks using only **propagation sequence order** (no timestamps) from a limited set of observers. It compresses the search space via geometric constraints (two earliest anchors + triangle inequality), selects top‑M candidates by a geometric score, and verifies them with max‑flow/min‑cut. Outperforms MCS, ROSE, and HiSOR in accuracy and speed, especially under strong community structures.

**Reference**: Zhao, J., Pan, L., & Ma, R. (2026). A Technique for Identifying Rumor Origins Within Communication Consistency Limitations.

## Requirements
- Python ≥ 3.10
- Packages: `networkx`, `ndlib`, `numpy`, `csv`, `random`, `timeit`, `collections`

Install: `pip install networkx ndlib numpy`

## Input Format
Graph CSV (undirected, no header required):
```
Source,Target
1,2
2,1
1,3
3,1
...
```
Observers and their sequence indicators are generated by IC model simulation (using NDlib) or provided from real data.

## Usage (Minimal Example)
```python

# Simulate or load observer_data = {node: sequence_index}

```

## Key Functions
- `find_anchors(obs)` → earliest two observers \(k_b, k_r\)
- `build_candidate_region(G, k_b, k_r)` → \(V_c\) via triangle inequality
- `top_m_screening(G, V_c, k_b, k_r, M)` → top‑M by \(\frac{d(v,k_b)+d(v,k_r)}{2}\)
- `maxflow_verification(G, candidates, observers)` → returns node with max flow

## Methodology Summary
1. **Candidate region** – \(V_c = \{v \mid |d(v,k_b)-d(v,k_r)| \le d(k_b,k_r)\}\) within radius \(d(k_b,k_r)/2\).
2. **Top‑M** – score = average distance to anchors; select smallest scores.
3. **Verification** – build flow network (candidate → observers → super‑sink); max flow value indicates structural consistency. Choose candidate with highest flow.

## Output
- Estimated source node (integer ID).
- Optional: distance error, accuracy, runtime, candidate list.
